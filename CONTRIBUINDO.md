# Como Contribuir

Obrigado pelo interesse em contribuir com este projeto!

## Passos para contribuir

1. Faça um fork do repositório.
2. Crie uma branch com sua feature ou correção: `git checkout -b minha-feature`
3. Faça commit das suas alterações: `git commit -m "Descrição clara da mudança"`
4. Envie para o seu fork: `git push origin minha-feature`
5. Abra um Pull Request descrevendo o que foi feito.

## Boas práticas

- Mantenha as mensagens de commit claras e objetivas.
- Siga o estilo de código já existente no projeto.
- Documente mudanças relevantes no README quando necessário.
